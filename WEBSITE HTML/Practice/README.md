# Practice

Extra practice based on the course so far. Sections 2 to 6 build one made-up website, **Sunny Side Café**, a little more in each section, the same way your yacht tours site grew.

| Folder | Practises | You build |
|---|---|---|
| `Section-1` | Your first page: headings, paragraphs, links | Your original practice page (left as it is) |
| `Section-2` | Module 2: images, links, comments, `id`, CSS colours and fonts | The café home page |
| `Section-3` | Module 3: more pages, a menu bar, `div`s, classes, text formatting | Menu and Contact pages |
| `Section-4` | Module 4: semantic HTML, a fixed header, flexbox, grid | A proper layout with cards and a footer |
| `Section-5` | Module 5: forms and validation | A "Book a Table" page |
| `Section-6` | Module 6: iframes and a little JavaScript | A "Find Us" page with a map |

## How to use a section

1. Open the section's `TASK.md`. In VS Code, press **Cmd+Shift+V** to read it nicely formatted.
2. Open the section's `index.html` in Chrome.
3. Work through the steps, typing the code yourself. Save and refresh Chrome after each step.
4. Try the **Bug hunt** before you open the answers.
5. When you're done, compare your work with the `solution/` folder.

Each section starts from the previous section's solution, so you can do any section on its own. Section 2 starts from a copy of your Section 1 page.
