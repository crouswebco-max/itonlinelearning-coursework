Tailwind, installed with npm

This page doesn't use the Play CDN. Tailwind is installed in this folder with npm, and the Tailwind CLI reads src/input.css, finds the classes used in the HTML, and writes only those into src/output.css.

Setting it up

  1. Step 1

    Install

    npm install

  2. Step 2

    Build the CSS

    npm run build

  3. Step 3

    Keep it building

    npm run watch

The custom theme

The @theme block in src/input.css adds names of my own, which then work like any built-in Tailwind class.

--color-tahiti

Used by text-tahiti, bg-tahiti and border-tahiti.

Trebuchet MS

--font-display

Used by font-display, which is set on the whole page.

Why use npm instead of the CDN?

  • Smaller. Only the classes I actually use end up in the file.
  • Offline. The page works with no internet, because the CSS is a local file.
  • Fixed version. Tailwind's version is pinned in package.json, so it can't change under me.
