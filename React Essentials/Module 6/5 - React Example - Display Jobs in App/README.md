# React Example: Display Jobs in the App

A one-page lesson on showing a job list in status columns, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Jobs in Columns** | The JobManager, JobColumn and JobCard component tree, filtering one array per column, and mapping categories, with a live board to add jobs to |
