# React Example: useEffect and Saving Jobs

A one-page lesson on `useEffect` and `localStorage`, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. The useEffect Hook** | Side effects, the dependency array (none, `[]`, `[jobs]`) and clean-up, with a live demo that changes the tab title |
| **2. Saving to localStorage** | Loading with `useState(() => ...)`, saving in `useEffect`, and clearing, with live notes that survive a refresh |
