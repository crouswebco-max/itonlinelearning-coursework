# React Example: Deleting Jobs

A one-page lesson on deleting items and resetting a form, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Deleting a Job** | `filter` by id, unique ids, passing the function down, and `window.confirm()` |
| **2. Resetting the Form** | A `resetForm` function called after adding, and why inputs must be controlled, with a live demo |
