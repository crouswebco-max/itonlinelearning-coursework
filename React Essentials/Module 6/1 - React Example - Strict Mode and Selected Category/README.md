# React Example: Strict Mode and Managing the Selected Category

A one-page lesson, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. React Strict Mode** | What `<React.StrictMode>` does in development, and why logs can appear twice |
| **2. Managing the Selected Category** | One category as a string, and many as an array toggled with `includes`, `filter` and `...`, with a live demo of both |
