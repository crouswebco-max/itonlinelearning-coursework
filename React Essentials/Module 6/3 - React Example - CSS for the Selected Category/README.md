# React Example: Add CSS to the Selected Category

A one-page lesson on showing which option is selected, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. A Class for the Selected Item** | Conditional `className` and template literals |
| **2. A Style Object per Category** | A `categoryStyles` object looked up by key, with transitions, in a live demo with a reset button |
