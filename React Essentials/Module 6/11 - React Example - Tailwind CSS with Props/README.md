# React Example: Tailwind CSS with Props

A one-page lesson on using Tailwind CSS in React components, built with React. Open `index.html` in a browser. It needs an internet connection, because React and Tailwind load from a CDN.

| Lesson | What it covers |
|---|---|
| **1. Utility Classes in className** | What utility-first means, common classes, and the `hover:` and `md:` prefixes |
| **2. Tailwind and Props Together** | A `Card` whose content and button colour come from props, spreading props with `{...card}`, and why class names must be written out in full, with three live cards |
