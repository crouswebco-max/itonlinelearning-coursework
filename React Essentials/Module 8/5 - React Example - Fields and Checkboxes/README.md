# React Example: Fields and Checkboxes

A one-page lesson on the password generator's controls, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Range Inputs and Checkboxes** | `type="range"` with `Number()`, and checkboxes with `checked` and `prev => !prev`, with a live demo |
| **2. Connecting Them to the Generator** | `useEffect` that regenerates whenever an option changes, and an error when no type is chosen, with a live generator |
