# React Example: Adding Copy and useRef

A one-page lesson on `useRef`, the Clipboard API and custom hooks, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. useRef** | Holding a DOM element in a ref and calling `focus()` and `select()`, with a live demo |
| **2. Copying to the Clipboard** | `navigator.clipboard.writeText`, selecting the text first, and error handling, with a live Copy button |
| **3. Custom Hooks** | Moving the generator's state and logic into `usePasswordGenerator`, and why that helps |
