# React Example: Password Generator

A one-page introduction to the password generator project, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Setting Up the Project** | The Vite and Tailwind CSS commands, `tailwind.config.js` and the `@tailwind` directives |
| **2. The State** | `length`, `numberAllowed`, `characterAllowed` and `password`, with a live generator, and why passwords should use `crypto.getRandomValues()` |
