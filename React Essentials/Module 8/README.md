# React Essentials: Module 8

This module builds a Password Generator with Vite and Tailwind CSS. Each practical folder has the app at the end of that step, and practical 8 is the finished version.

| Work | What it is |
|---|---|
| [1. React Example: Password Generator](1%20-%20React%20Example%20-%20Password%20Generator/) | Lesson page: Vite and Tailwind setup, the state, and secure randomness |
| [2. Practical Activity: Setting Up a Password Generator](2%20-%20Practical%20Activity%20-%20Setting%20Up%20a%20Password%20Generator/) | The project, the four state variables, the UI, and the Generate and Copy bonuses |
| [3. React Example: useCallback](3%20-%20React%20Example%20-%20useCallback/) | Lesson page: what `useCallback` does, with a live counter of new functions |
| [4. Practical Activity: Password Generator Functionality](4%20-%20Practical%20Activity%20-%20Password%20Generator%20Functionality/) | `passwordGenerator` with `useCallback`, a guaranteed character from each set, feedback, a strength meter and excluding similar characters |
| [5. React Example: Fields and Checkboxes](5%20-%20React%20Example%20-%20Fields%20and%20Checkboxes/) | Lesson page: range inputs, checkboxes, and regenerating with `useEffect` |
| [6. Practical Activity: Password Generator UI](6%20-%20Practical%20Activity%20-%20Password%20Generator%20UI/) | A checkbox for every type, auto-generate, Copy, validation and keyboard shortcuts |
| [7. React Example: Copy and useRef](7%20-%20React%20Example%20-%20Copy%20and%20useRef/) | Lesson page: `useRef`, the Clipboard API and custom hooks |
| [8. Practical Activity: Advanced Password Generator](8%20-%20Practical%20Activity%20-%20Advanced%20Password%20Generator/) | The `usePasswordGenerator` hook, copying with `useRef`, and several passwords at once |

The practicals are Vite projects. In each `password-generator` folder, run `npm install` once, then `npm run dev`.
