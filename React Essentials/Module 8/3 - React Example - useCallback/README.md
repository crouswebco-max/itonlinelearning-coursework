# React Example: useCallback

A one-page lesson on the `useCallback` hook, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. What useCallback Does** | Keeping the same function between renders, the dependency array, and why a missing dependency is a bug |
| **2. Why It Matters** | Functions used by `useEffect`, with a live counter of renders against new functions made |
