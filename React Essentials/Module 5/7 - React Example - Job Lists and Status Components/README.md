# React Example: Building Job Lists and Status Components

A one-page lesson on showing one list of jobs across status columns, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. One List, Three Columns** | Filtering one jobs array per column, `deleteJob` with `filter` and `updateJobStatus` with `map`, with a live board |
| **2. How the Data Flows** | App to JobColumn to JobStatus, passing functions down through props |
