# React Example: Creating Button Components and Props Value

A one-page lesson on reusable components driven by props, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. A Reusable Button** | `variant`, `children` and `...rest` props, with three live buttons from one component |
| **2. Reusable Job Columns** | One `JobColumn` used three times with a different title, image and jobs, and importing images |
