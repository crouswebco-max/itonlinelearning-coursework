# React Example: Functional Aspects for Forms

A one-page lesson on handling bigger forms, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. One Object, One Handler** | `jobDetails` state and `handleInputChange` using each input's `name` |
| **2. Validation and Feedback** | Errors worked out from the values, showing them once a field is touched, a disabled submit button, success messages and reset, with a live form |
