# React Essentials: Module 5

This module builds one Job Management app step by step. Each practical activity folder has the app as it was at the end of that step.

| Work | What it is |
|---|---|
| [1. React Example: Scheduled Task Forms](1%20-%20React%20Example%20-%20Scheduled%20Task%20Forms/) | Lesson page: the form elements and a `JobForm` component, with a live form |
| [2. Practical Activity: Job Management Form](2%20-%20Practical%20Activity%20-%20Job%20Management%20Form/) | `JobForm`: title, category buttons, status dropdown and submit, with state, logging and validation |
| [3. React Example: CSS Form App Layout](3%20-%20React%20Example%20-%20CSS%20Form%20App%20Layout/) | Lesson page: a CSS file per component, variables, flexbox and grid, states and media queries |
| [4. Practical Activity: Styling the Job Form](4%20-%20Practical%20Activity%20-%20Styling%20the%20Job%20Form/) | `AppForm.css`: a fully styled, responsive form with transitions and dark mode |
| [5. React Example: Button Components and Props](5%20-%20React%20Example%20-%20Button%20Components%20and%20Props/) | Lesson page: a reusable `Button` with `variant`, `children` and `...rest`, and reusable columns |
| [6. Practical Activity: Reusable Components](6%20-%20Practical%20Activity%20-%20Reusable%20Components/) | One `JobColumn` used for three statuses, with moving jobs, adding and search |
| [7. React Example: Job Lists and Status Components](7%20-%20React%20Example%20-%20Job%20Lists%20and%20Status%20Components/) | Lesson page: one jobs array filtered into columns, delete and status updates |
| [8. Practical Activity: Dynamic Functionality](8%20-%20Practical%20Activity%20-%20Dynamic%20Functionality/) | Add, update and delete jobs, drag and drop, search and `localStorage` |
| [9. React Example: Functional Aspects for Forms](9%20-%20React%20Example%20-%20Functional%20Aspects%20for%20Forms/) | Lesson page: one object and one handler, validation, disabled submit and feedback |
| [10. Practical Activity: Enhanced Form Handling](10%20-%20Practical%20Activity%20-%20Enhanced%20Form%20Handling/) | Full form handling with per-field errors, reset, success messages, a `JobList`, edit and `localStorage` |

The practical activities are Create React App projects. In each app's folder, run `npm install` once, then `npm start`.

The module's Test Your Knowledge quiz is taken on the course website, so it isn't in this folder.
