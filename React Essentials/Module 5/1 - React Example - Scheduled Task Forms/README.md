# React Example: Scheduled Task Forms

A one-page lesson on building the job management form, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. The Form Elements** | An input, category buttons, a status dropdown and a submit button, and why category buttons need `type="button"` |
| **2. Organising the Form** | A `JobForm` component with class names ready for styling, and a live form that adds jobs |
