# React Example: CSS Form App Layout

A one-page lesson on styling the job management form, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. A CSS File per Component** | `AppForm.css` next to `AppForm.js`, consistent class names, and CSS variables |
| **2. Layout, States and Responsive Design** | Flexbox and Grid, `:focus`, `:hover`, `:active` and transitions, and a media query, with a live styled form to try |
