# React Essentials: Module 10

APIs, using The Movie Database (TMDB) with the movie review app from Module 9. The folders follow the course's lessons (9–13).

| Work | What it is |
|---|---|
| [1. React Example: Introduction to API (Lesson 9)](1%20-%20React%20Example%20-%20Introduction%20to%20API/) | Lesson page: requests, responses, status codes and JSON, with a live fetch |
| [2. React Example: API Key and Methods (Lesson 10)](2%20-%20React%20Example%20-%20API%20Key%20and%20Methods/) | Lesson page: getting a TMDB key (from the course update), `?api_key=` against a Bearer token, and `.env.local` |
| [3. React Example: Practice Exercise (Lesson 11)](3%20-%20React%20Example%20-%20Practice%20Exercise/) | Lesson page: a `MovieList` that fetches and shows movies, with loading and error states |
| [4. React Example: Filtering and Sorting (Lesson 12)](4%20-%20React%20Example%20-%20Filtering%20and%20Sorting/) | Lesson page: rating filters and lodash `orderBy`, with a live demo |
| [5. React Example: Reusable Components (Lesson 13)](5%20-%20React%20Example%20-%20Reusable%20Components/) | Lesson page: `FilterGroup`, and one `MovieList` for three lists |
| [6. Movie Review App (Lessons 9–13)](6%20-%20Movie%20Review%20App%20%28Lessons%209-13%29/) | ReelTalk with real TMDB data: Popular, Top Rated and Upcoming, filters, sorting and reusable components |

The app needs a free TMDB API key in `movie-review-app/.env.local`. The steps are in [its README](6%20-%20Movie%20Review%20App%20%28Lessons%209-13%29/).
