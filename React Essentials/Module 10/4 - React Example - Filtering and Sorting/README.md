# React Example: Filtering and Sorting (Lesson 12)

A one-page lesson on filtering movies by rating and sorting them with lodash, built with React. Open `index.html` in a browser. It needs an internet connection, because React and lodash load from a CDN. The demo uses made-up sample movies.

| Lesson | What it covers |
|---|---|
| **1. Filtering by Rating** | Keeping all the movies and the shown movies in separate state, and a filter you can turn off by clicking again |
| **2. Sorting with lodash** | `_.orderBy`, one `handleSort` for both selects using `name`, and one effect that filters then sorts, with a live demo |
