# React Example: Introduction to API (Lesson 9)

A one-page lesson on what an API is and how React gets data from one, built with React. Open `index.html` in a browser (it needs an internet connection).

| Lesson | What it covers |
|---|---|
| **1. What is an API?** | Requests and responses, endpoints, methods, status codes and JSON, using TMDB as the example |
| **2. Fetching Data in React** | `fetch` inside `useEffect`, with a live request to the free JSONPlaceholder practice API |
