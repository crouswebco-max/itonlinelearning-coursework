# React Example: API Key and Methods to Access the API (Lesson 10)

A one-page lesson on getting and using a TMDB API key, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Getting Your API Key** | The steps from the course update for finding the key on the current TMDB website |
| **2. Two Ways to Send It** | The key as a `?api_key=` query parameter (the course's way) or a Bearer token in a header, and keeping it in `.env.local` with `import.meta.env` |
