# React Example: Practice Exercise (Lesson 11)

A one-page lesson on fetching movies into a `MovieList`, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN). The demo uses made-up sample movies, so no API key is needed.

| Lesson | What it covers |
|---|---|
| **1. The Practice Exercise** | A `MovieList` that fetches `/movie/popular` in `useEffect` and maps the results to `MovieCard`s, and building poster addresses |
| **2. Loading and Error States** | Showing loading, an error or the data, with a live demo that can pretend the key is wrong |
