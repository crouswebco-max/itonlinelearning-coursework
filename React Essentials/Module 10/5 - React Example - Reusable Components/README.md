# React Example: Adding Reusable Components (Lesson 13)

A one-page lesson on making the movie app's parts reusable, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. A Reusable FilterGroup** | Rating buttons with `minRating`, `onRatingClick` and `ratings` props, and why they should be buttons |
| **2. One MovieList, Three Lists** | `type`, `title` and `emoji` props for Popular, Top Rated and Upcoming, with two live lists that each keep their own filter |
