# React Example: useState

A one-page lesson on the `useState` hook, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. The useState Syntax** | `const [count, setCount] = useState(0)`, array destructuring, naming, and the rules of hooks |
| **2. Updating State Correctly** | Never change state directly, and why `prev => prev + 1` is needed for several updates in a row, with a live "+3" demo showing the difference |
| **3. State with Different Types** | Booleans, arrays and objects, copying with `...` before changing, with a live demo |
