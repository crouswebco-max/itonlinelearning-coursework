# React Example: Style Attributes

A one-page lesson on styling in React, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Inline Styles** | `style={{ }}` takes an object: camelCase names, numbers as pixels, commas between properties, and style objects in variables |
| **2. JSX Attributes** | `className`, `htmlFor`, `onClick`, `tabIndex`, and dynamic attributes like `disabled={isDisabled}` |
| **3. Dynamic and Combined Styles** | Picking styles with a condition and combining them with `...`, with a live demo (theme toggle, bigger text, disable a button) |
| **4. Limits of Inline Styles** | No `:hover`, media queries or keyframes, hover with `onMouseEnter` / `onMouseLeave`, and when to use a CSS file instead |
