# React Example: Practice Exercise Using useState

A practice task list that brings Module 3 together, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Practice: A Task List** | A live app: add tasks with a form, tick them off, filter All / To do / Done, delete them, and a "done" count |
| **2. The Patterns Behind It** | Add with `[...items, newItem]`, update with `map`, delete with `filter`, values worked out from state, and keys |
