# React Example: Working with State and Handling User Values

A one-page lesson on forms in React, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Controlled Inputs** | `value` from state plus `onChange`, with a live demo showing the state as you type |
| **2. Forms with Several Inputs** | One state object and one `handleChange` using `[name]`, plus checkboxes and selects, with a live sign-up form |
| **3. Submitting a Form** | `onSubmit`, `preventDefault()`, validation and resetting |
