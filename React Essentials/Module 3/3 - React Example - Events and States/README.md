# React Example: Events and States

A one-page lesson on events and why React needs state, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Handling Events** | `onClick`, `onChange`, `onMouseEnter` and `onFocus`, passing a function (not calling it), and arrow functions for passing values. A live demo shows the last event |
| **2. The Event Object** | `event.target`, `event.target.value` and `event.preventDefault()` |
| **3. Why We Need State** | Two counters side by side: a regular variable that never updates the page, and `useState` that does, with the reasons |
