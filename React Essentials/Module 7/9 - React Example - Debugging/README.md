# React Example: Debugging (Browser and Breakpoints)

A one-page lesson on finding bugs with the browser's developer tools, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. The Browser's Debugging Tools** | The Console and Sources tabs, breakpoints, stepping through code, `debugger;` and React Developer Tools |
| **2. Finding a Real Bug** | Strings joining instead of adding: a live side-by-side of the buggy and fixed calculators, and the `+` / `parseFloat` fix |
