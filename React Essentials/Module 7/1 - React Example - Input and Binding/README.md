# React Example: Input and Binding

A one-page lesson on two-way binding for the Investment Calculator, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Two-Way Binding** | `value` plus `onChange`, with a live demo showing the state is a string after typing |
| **2. One Object, One Handler** | The `userInput` object and `handleChange(inputIdentifier, newValue)` with `...`, `[inputIdentifier]` and `+newValue`, with four live inputs |
