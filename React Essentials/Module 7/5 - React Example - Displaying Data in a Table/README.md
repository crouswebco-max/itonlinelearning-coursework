# React Example: Displaying Data in a Table

A one-page lesson on turning results into a table, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. The Results Table** | Mapping years to rows, working out total interest and invested capital, keys, and an early return for a zero duration, with a live table |
