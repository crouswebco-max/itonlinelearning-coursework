# React Essentials: Module 7

This module continues the Investment Calculator (the Money Builder App) from Module 6. Each practical folder has the app at the end of that step. Practical 8 is the finished app.

| Work | What it is |
|---|---|
| [1. React Example: Input and Binding](1%20-%20React%20Example%20-%20Input%20and%20Binding/) | Lesson page: two-way binding and one handler for four inputs |
| [2. Practical Activity: User Input Component](2%20-%20Practical%20Activity%20-%20User%20Input%20Component/) | `UserInput` with its own state, validation, reset and a currency switch |
| [3. React Example: Handling Output Results](3%20-%20React%20Example%20-%20Handling%20Output%20Results/) | Lesson page: lifting state up and working out results from props |
| [4. Practical Activity: Output Component](4%20-%20Practical%20Activity%20-%20Output%20Component/) | `OutputData` table, input errors, the highest-interest row and an SVG chart |
| [5. React Example: Displaying Data in a Table](5%20-%20React%20Example%20-%20Displaying%20Data%20in%20a%20Table/) | Lesson page: rows from `.map()` and worked-out columns |
| [6. Practical Activity: Results Table](6%20-%20Practical%20Activity%20-%20Results%20Table/) | Formatted `#result` table with a totals row, a yearly/monthly toggle and a chart |
| [7. React Example: Generating a Report](7%20-%20React%20Example%20-%20Generating%20a%20Report/) | Lesson page: a live jsPDF download, `useMemo` and `useCallback` |
| [8. Practical Activity: Enhancing the Calculator](8%20-%20Practical%20Activity%20-%20Enhancing%20the%20Calculator/) | The finished app: validation, a PDF report, `useMemo`, loading, recharts and scenario comparison |
| [9. React Example: Debugging](9%20-%20React%20Example%20-%20Debugging/) | Lesson page: DevTools, breakpoints and the strings-join-instead-of-add bug |
| [10. Practical Activity: Debugging in React](10%20-%20Practical%20Activity%20-%20Debugging%20in%20React/) | Buggy and fixed calculators side by side, with a `useInvestmentForm` hook |

The practicals are Vite projects. In each `moneybuilderapp` folder, run `npm install` once, then `npm run dev`.
