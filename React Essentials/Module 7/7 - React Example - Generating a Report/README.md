# React Example: Generating a Report

A one-page lesson on making a PDF report with a library, built with React. Open `index.html` in a browser. It needs an internet connection, because React and jsPDF load from a CDN.

| Lesson | What it covers |
|---|---|
| **1. A PDF with jsPDF** | Installing and importing `jspdf`, and a `generatePDF` function, with a live **Download PDF Report** button that really downloads a file |
| **2. Showing the Button, useMemo and useCallback** | Rendering the button only when there are results, and remembering values and functions between renders |
