# React Example: Handling Output Results

A one-page lesson on sharing input between components and showing results, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Lifting State Up** | Moving `userInput` into `App` so `UserInput` and `OutputData` can share it |
| **2. Working Out the Output** | `OutputData` calculates from its props on every render, and formats the money, with a live demo |
