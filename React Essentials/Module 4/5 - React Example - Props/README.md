# React Example: Props

A one-page lesson on props, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Passing Props** | Parent to child, destructuring, default values, read-only props and the `key` prop |
| **2. Passing Functions as Props** | Data flows down and actions flow up: `onDeleteJob` passed from App to JobList to JobItem, with a live demo |
