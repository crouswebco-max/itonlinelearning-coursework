# React Example: Conditional Templates

A one-page lesson on showing different JSX depending on the data, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Four Ways to Choose** | `if` with an early return, the ternary, `&&` and conditional classes, with a live demo (loading / error / done, log in and out, show and hide) |
| **2. Conditions in a Real App** | A job board component tree, and how React only updates the parts that change |
