# React Example: Add and Remove Elements

A one-page lesson on adding and removing items in a list, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Adding Elements** | `setItems([...items, newItem])`, why not `push()`, and unique ids |
| **2. Removing Elements** | `filter` to remove by id, and why the click handler needs an arrow function, with a live shopping list demo |
| **3. Adding from a Form** | A new-item object in state, one `handleInputChange` with `[name]`, validating, adding and clearing |
