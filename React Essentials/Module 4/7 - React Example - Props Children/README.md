# React Example: Props Children

A one-page lesson on `props.children`, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. The children Prop** | Content between the tags arrives as `children`, with three live cards holding different content |
| **2. Why Use children?** | Flexible layouts, less prop drilling, and combining settings props with children |
