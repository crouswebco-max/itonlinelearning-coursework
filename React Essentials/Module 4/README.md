# React Essentials: Module 4

| Work | What it is |
|---|---|
| [1. React Example: Add and Remove Elements](1%20-%20React%20Example%20-%20Add%20and%20Remove%20Elements/) | Lesson page: adding with `[...items, item]`, removing with `filter`, and adding from a form |

The practical activities are Create React App projects. In each app's folder, run `npm install` once, then `npm start`.

The module's Test Your Knowledge quiz is taken on the course website, so it isn't in this folder.
