# React Example: Expressions and Practice in JSX

A one-page lesson on JSX expressions, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. What is an Expression?** | Anything in `{ }` must produce a value. Why `if` and `for` can't go inside braces |
| **2. Maths, Template Literals and Functions** | `{price * quantity}`, `.toFixed(2)`, backtick strings with `${ }`, and calling a function in JSX, all rendered live |
| **3. Conditions in JSX** | The ternary `? :`, `&&` (and the "0 on the page" trap), and `if / else` inside a function |
| **4. Practice** | A slider for the number of open jobs. The heading, badge, sentence, forecast and warning all update from JSX expressions |
