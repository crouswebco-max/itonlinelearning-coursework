# React Example: Creating Variables in JavaScript

A one-page lesson on JavaScript variables and how to show them in React, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Declaring Variables** | `const`, `let` and `var`, when to use each, and naming rules (camelCase, `is`/`has` for booleans) |
| **2. Data Types** | Strings, numbers, booleans, arrays, objects, `undefined` and `null`, with `typeof` |
| **3. Variables in JSX** | Creating variables before `return` and showing them with `{ }`, plus a live demo that updates as you type your name |
| **4. What JSX Can Render** | A table of real results: what shows, what shows nothing (booleans), how arrays join, and why a whole object causes an error |
