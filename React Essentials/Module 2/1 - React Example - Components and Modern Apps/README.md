# React Example: Components and Modern Apps

A one-page lesson on React components, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. React Components** | A component is a function that returns JSX, with a live `Welcome` component and the rules (capital letter, one parent element, closed tags, `className`) |
| **2. Passing Data with Props** | Props as function arguments, destructuring, and why props are read-only |
| **3. Putting Components Together** | `ProductList` uses `.map()` to render three `ProductCard`s with a `key`. Each card has its own **Like** state |
| **4. Building Modern Apps** | Single-page apps, thinking in a component tree, one component per file with `import` / `export`, and good habits |
