# React Example: Creating Movie Display Components

A one-page lesson on `MovieCard` and `MovieList`, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN). The movies are made-up sample data. Real data comes from an API in Module 10.

| Lesson | What it covers |
|---|---|
| **1. The MovieCard Component** | One movie from props (poster, title, year, genre and rating), and keeping display components simple |
| **2. The MovieList Component** | Mapping movies to cards in a CSS Grid, with a live list you can sort and save favourites in |
