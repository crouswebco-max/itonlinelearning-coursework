# React Essentials: Module 9

The start of a movie review app. The folders follow the course's lesson numbers (Lessons 5–8).

| Work | What it is |
|---|---|
| [1. React Example: Movie Review App (Lesson 5)](1%20-%20React%20Example%20-%20Movie%20Review%20App/) | Lesson page: setting up, adding a custom font with `@font-face`, and CSS Modules |
| [2. Practical Activity: Setting Up a Movie Review App](2%20-%20Practical%20Activity%20-%20Setting%20Up%20a%20Movie%20Review%20App/) | ReelTalk: Vite, Montserrat WOFF fonts, CSS Modules, a Header, a Footer and a responsive layout |
| [3. React Example: Adding Headers (Lesson 6)](3%20-%20React%20Example%20-%20Adding%20Headers/) | Lesson page: a header component and a menu for small screens |
| [4. React Example: Adding Components (Lesson 7)](4%20-%20React%20Example%20-%20Adding%20Components/) | Lesson page: planning the component tree, and a live search and genre filter |
| [5. React Example: Movie Display Components (Lesson 8)](5%20-%20React%20Example%20-%20Movie%20Display%20Components/) | Lesson page: `MovieCard` and `MovieList`, with live sorting and favourites |

The practical is a Vite project. In `movie-review-app`, run `npm install` once, then `npm run dev`.
