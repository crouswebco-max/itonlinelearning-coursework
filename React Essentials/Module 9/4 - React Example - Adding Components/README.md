# React Example: Adding Components

A one-page lesson on planning and connecting the movie app's components, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Planning the Components** | A component tree for the movie app (Header, SearchBar, GenreFilter, MovieList, MovieCard, Footer) and the files |
| **2. Connecting Them** | `App` owns the search and genre state and passes it down, with a live search and genre filter |
