# React Example: Movie Review App

A one-page introduction to the movie review project, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. Setting Up the Project** | The Vite commands and cleaning up the starter code |
| **2. Adding a Custom Font** | Montserrat as a WOFF file in `src/assets/fonts`, with `@font-face` and one declaration per weight |
| **3. CSS Modules** | `*.module.css` files imported as `styles`, and why their class names can't clash |
