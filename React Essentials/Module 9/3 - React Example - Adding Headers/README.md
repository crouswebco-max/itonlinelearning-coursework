# React Example: Adding Headers

A one-page lesson on building the movie app's header, built with React. Open `index.html` in a browser (it needs an internet connection, because React loads from a CDN).

| Lesson | What it covers |
|---|---|
| **1. A Header Component** | `<header>` and `<nav>`, links from an array, and a sticky header |
| **2. A Menu for Small Screens** | A menu button with state, `aria-expanded` and `aria-current`, with a live header that folds up on narrow screens |
