# JavaScript Essentials: Module 10

AJAX and asynchronous JavaScript. Each practice is a separate AJAX example that loads real data from the free [JSONPlaceholder](https://jsonplaceholder.typicode.com/) API, so you need to be online. Work through them in order.

| Practice | What it is |
|---|---|
| [1. Asynchronous JavaScript](AJAX%20Example%201%20-%20Asynchronous%20JavaScript/) | What asynchronous means, with an `XMLHttpRequest` AJAX request and its `readyState` stages |
| [2. Callbacks](AJAX%20Example%202%20-%20Callbacks/) | AJAX with `callback(error, data)`, and "callback hell" |
| [3. Promises](AJAX%20Example%203%20-%20Promises/) | AJAX wrapped in a promise: `.then()`, `.catch()`, chaining and `Promise.all()` |
| [4. Async / Await](AJAX%20Example%204%20-%20Async%20Await/) | The same requests with `async` / `await` and `try` / `catch`, one after another versus all at once |
| [5. Fetch API](AJAX%20Example%205%20-%20Fetch%20API/) | A small app that loads users and their posts with `fetch()` |
