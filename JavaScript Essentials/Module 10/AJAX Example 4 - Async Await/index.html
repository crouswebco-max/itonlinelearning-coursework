AJAX with Async / Await

async and await are a tidier way to use promises. Inside an async function, await pauses that function until the data arrives, so the code reads top to bottom. The rest of the page keeps working.

  • Errors are caught with try / catch.
  • One after another: each await waits for the request before it.
  • All at once: await Promise.all() sends them together, which is faster.

    The same messages also go to the browser console (F12, then Console).
