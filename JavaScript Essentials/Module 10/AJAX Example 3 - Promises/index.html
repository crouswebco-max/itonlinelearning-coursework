AJAX with Promises

A promise stands for a result that is not ready yet. It starts pending, then is fulfilled (resolve) or rejected (reject). Here getData(url) wraps the AJAX request in a promise.

  • .then() runs when it works, .catch() when it fails, .finally() either way.
  • Chain: the same user, posts and comments as callback hell, but flat.
  • Promise.all() sends three requests at once and waits for all of them.

    The same messages also go to the browser console (F12, then Console).
