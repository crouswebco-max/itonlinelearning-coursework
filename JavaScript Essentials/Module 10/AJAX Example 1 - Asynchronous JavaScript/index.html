Asynchronous JavaScript with AJAX

AJAX (Asynchronous JavaScript And XML) means getting data from a server without reloading the page. The request is asynchronous: JavaScript sends it, carries on with the next lines, and deals with the answer when it arrives.

  • Synchronous code: runs one line after another, in order.
  • AJAX request: the line after send() runs before the data arrives.
  • Watch readyState: the stages a request goes through, from 1 to 4.

    The same messages also go to the browser console (F12, then Console).
