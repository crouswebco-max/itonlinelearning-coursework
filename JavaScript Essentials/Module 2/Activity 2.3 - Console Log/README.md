# Activity 2.3: Log Information to the Console

A page that logs a message to the browser's console. Open `index.html` in a browser, then open the console to see it: press F12 (or right-click the page, choose **Inspect**, then the **Console** tab).

## How it works

- `index.html` links the JavaScript file with `<script src="script.js"></script>`.
- `script.js` runs `console.log("...")` as soon as the page loads.
- The message shows in the console only, not on the page itself.

## Things to notice

- **`console.log()` is for checking your code.** Visitors don't see it, but you can use it to see what your code is doing.
- **The console shows which file and line the message came from** (`script.js:2`), on the right of the message.
