# Activity 2.1: Write Your First JavaScript

A web page that shows an alert message as soon as it loads. Open `index.html` in a browser and the alert pops up straight away.

## How it works

- The JavaScript sits between a pair of `<script>` tags at the bottom of `index.html`.
- `alert("...")` is a function built into the browser. It shows a pop-up box with the message and waits for you to click **OK**.
- The browser runs the script as soon as it reaches it, so the alert appears when the page loads. The heading may not show until you click **OK**, because `alert()` pauses the page.
