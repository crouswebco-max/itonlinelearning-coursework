# 6.5 Practice Activities: Mixed Mock Exam (30 questions)

Covers all four domains, in about the exam's proportions. **Aim for 45 minutes** (the same pace as the real exam), and try for **24 out of 30 (80%)** or more before booking.

The answers and explanations are at the bottom.

---

## Answers and explanations

| # | Answer | Why |
|---|---|---|
| 1 | **B** | One of the six advantages. A is back to front: it's fixed expense traded for variable |
| 2 | **B** | Rehost = lift and shift, with no changes |
| 3 | **C** | Sustainability |
| 4 | **B** | Hybrid = on-premises and cloud connected together |
| 5 | **A** | Elasticity scales up **and down** with demand |
| 6 | **C** | People = skills, training and culture |
| 7 | **B, D** | Security groups and IAM are **in** the cloud, so they're yours. The others are AWS's |
| 8 | **B** | Roles give temporary credentials, with no stored keys |
| 9 | **A** | CloudTrail records API calls: who did what |
| 10 | **B** | Shield Standard is automatic and free |
| 11 | **A** | Artifact holds the compliance reports |
| 12 | **C** | GuardDuty does threat detection |
| 13 | **C** | MFA, and don't use it for daily work |
| 14 | **B** | NACLs support deny rules. Security groups can't deny |
| 15 | **A** | Secrets Manager rotates secrets |
| 16 | **B** | Lambda is serverless and event-driven |
| 17 | **B** | RDS is a managed relational database |
| 18 | **B** | Intelligent-Tiering moves data automatically |
| 19 | **B** | Several AZs give high availability |
| 20 | **B** | Route 53 is DNS |
| 21 | **A** | CloudFormation is infrastructure as code |
| 22 | **B** | Direct Connect is a private, dedicated line |
| 23 | **A** | Athena runs SQL on S3 |
| 24 | **B** | SNS is publish/subscribe, one to many |
| 25 | **B** | Cognito handles app users' sign-in |
| 26 | **C** | Spot is the cheapest, and interruptible |
| 27 | **B** | The Pricing Calculator estimates **before** building |
| 28 | **B** | Business is the cheapest plan with 24/7 phone support |
| 29 | **A** | Trusted Advisor gives best-practice checks |
| 30 | **A, C** | One bill, and combined volume discounts |
