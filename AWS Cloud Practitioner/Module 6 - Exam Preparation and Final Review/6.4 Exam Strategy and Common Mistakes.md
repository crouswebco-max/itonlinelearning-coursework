# 6.4 Exam Strategy and Common Mistakes

## Strategy

1. **First pass:** answer everything you're sure of. **Flag** anything that takes more than about 90 seconds.
2. **Second pass:** go back to the flagged questions.
3. **Last minutes:** make sure **nothing is blank**. There's no penalty for guessing.
4. **For each question:**
   - Read the **last sentence first**: what is it actually asking?
   - Underline the **key words**: *MOST cost-effective*, *LEAST operational overhead*, *MOST secure*, *highly available*.
   - **Rule out** the clearly wrong answers.
   - Check how many to choose: **"Choose TWO"** needs exactly two.

## Key words and what they point to

| The question says… | Usually points to… |
|---|---|
| "**Least operational overhead**" or "**fully managed**" | Serverless or managed (Lambda, DynamoDB, RDS, Fargate) |
| "**Most cost-effective**" and "**can be interrupted**" | Spot Instances |
| "**Highly available**" | Several Availability Zones |
| "**Disaster recovery**" | Another Region |
| "**Temporary credentials**" | IAM roles |
| "**Who** did it?" | CloudTrail |
| "**Performance** or **alarm**" | CloudWatch |
| "**Compliance reports**" | Artifact |
| "**Recommendations**" | Trusted Advisor |
| "**Estimate** before building" | Pricing Calculator |

## Common mistakes

| Mistake | Remember |
|---|---|
| Mixing up **CloudTrail** and **CloudWatch** | Trail = **who did what**. Watch = **performance** |
| Mixing up **security groups** and **NACLs** | SG = instance, stateful, allow only. NACL = subnet, stateless, can deny |
| Thinking AWS patches **EC2** | **You** patch EC2. AWS patches **RDS** and the other managed services |
| Mixing up **Polly** and **Transcribe** | Polly **speaks** (text to speech). Transcribe **writes** (speech to text) |
| **Scalability** and **elasticity** | Elasticity **also scales down** automatically |
| **Cost Explorer** and **Budgets** | Explorer = **past**. Budgets = **alerts** |
| **Support plan** response times | Business < 1 hour · On-Ramp < 30 minutes · Enterprise < 15 minutes |
| **GuardDuty**, **Inspector** and **Macie** | Threats · vulnerabilities · sensitive data in S3 |
| **IAM** and **Cognito** | IAM = your AWS account's users. Cognito = **your app's** customers |
| Picking just one answer on "**Choose TWO**" | Always check how many are needed |
| Choosing a service because it **sounds** right | AWS sometimes uses made-up names. If you've never heard of it, be suspicious |
