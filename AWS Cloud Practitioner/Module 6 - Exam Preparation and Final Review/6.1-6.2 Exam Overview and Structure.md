# 6.1–6.2 Exam Overview and Structure

## The exam at a glance

| | |
|---|---|
| **Name** | AWS Certified Cloud Practitioner |
| **Code** | **CLF-C02** |
| **Questions** | **65**: 50 scored and 15 unscored (you can't tell which) |
| **Types** | **Multiple choice** (1 correct out of 4) and **multiple response** (2 or more correct out of 5 or more) |
| **Time** | **90 minutes**, about 1 minute 20 seconds per question |
| **Passing score** | **700** out of 1000 (scaled) |
| **Penalty for guessing** | **None**, so answer everything |
| **Cost** | About $100 USD (check the current price when booking) |
| **Where** | A **Pearson VUE** test centre, or **online** with a proctor watching by webcam |
| **Valid for** | 3 years |

## The four domains

| Domain | Weight | About how many of the 50 scored questions |
|---|---|---|
| 1. Cloud Concepts | 24% | 12 |
| 2. Security and Compliance | 30% | 15 |
| 3. Cloud Technology and Services | 34% | 17 |
| 4. Billing, Pricing and Support | 12% | 6 |

## Booking

1. Go to **[aws.amazon.com/certification](https://aws.amazon.com/certification/)**, sign in to (or create) an **AWS Certification account**, and choose **Cloud Practitioner**.
2. Schedule it with **Pearson VUE**: at a test centre, or online.
3. **For an online exam:** run the **system test** beforehand, and have a **quiet room**, a **clear desk**, **photo ID** and a webcam. No phones, notes or second screens.
4. If English isn't your first language, you can request **30 minutes extra time** (ESL +30) before booking.

*Check the [official exam page](https://aws.amazon.com/certification/certified-cloud-practitioner/) for the latest details.*
