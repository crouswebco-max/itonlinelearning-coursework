# 2.1–2.2 Introduction to Cloud Concepts and Basic IT Concepts

**Cloud Concepts** is Domain 1 of the exam (**24%**). Before the cloud makes sense, it helps to know the basic building blocks of IT.

## The building blocks

| Term | What it is | Everyday example |
|---|---|---|
| **Server** | A computer that provides a service to other computers, like hosting a website | The computer that sends you a web page |
| **Compute** | The processing power (CPU) and memory (RAM) that runs programs | The "brain" of a server |
| **Storage** | Where data is kept: files, images, backups | A hard drive or SSD |
| **Database** | Organised data that's quick to search and update | A shop's list of customers and orders |
| **Network** | How computers connect and send data to each other | The internet, or a Wi-Fi network |
| **Data centre** | A building full of servers, with power, cooling and security | Where "the cloud" physically lives |
| **Client** | The device asking for something | My laptop's browser |

## How a website works (client and server)

1. I type a web address into my browser (the **client**).
2. **DNS** turns the name (like `example.com`) into the server's **IP address**.
3. The browser sends a request over the **network** to the **server**.
4. The server runs code (**compute**), maybe reads from a **database**, and sends back the page.

## Running your own servers ("on-premises")

Before the cloud, a company ran its own servers in its own building (**on-premises**). That means:

- **Buying hardware up front**, a big cost before you know if you'll need it
- **Guessing capacity**: buy too little and the site crashes when busy, buy too much and you waste money
- Paying for **space, power, cooling, security and staff**
- **Slow to change**: ordering and setting up new servers can take weeks
- **Hard to go global**: reaching users in other countries means building or renting data centres there

The cloud solves these problems, which is the rest of this module.
