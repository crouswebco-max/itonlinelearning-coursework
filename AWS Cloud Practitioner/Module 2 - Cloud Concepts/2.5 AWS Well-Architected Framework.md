# 2.5 The AWS Well-Architected Framework

A set of best practices for designing systems on AWS that are secure, reliable, efficient and cost-effective. It's organised into **six pillars**.

## The six pillars

| Pillar | The question it asks | Key ideas |
|---|---|---|
| **1. Operational Excellence** | Can we run and improve the system well? | Automate changes (infrastructure as code), make small frequent changes, learn from failures |
| **2. Security** | Is the data and the system protected? | Least privilege, traceability (logging), security at every layer, encryption |
| **3. Reliability** | Does it work correctly and recover from failure? | Recover automatically, scale to meet demand, test recovery, use several AZs |
| **4. Performance Efficiency** | Are we using resources efficiently as needs change? | Use the right resource type, go global in minutes, use serverless and managed services, experiment |
| **5. Cost Optimisation** | Are we avoiding unnecessary cost? | Pay only for what you need, measure spending, rightsize, use managed services |
| **6. Sustainability** | Are we reducing the environmental impact? | Use only what's needed, pick efficient hardware and Regions, maximise utilisation |

**Memory trick:** "**O**ld **S**ailors **R**arely **P**ass **C**hilly **S**eas": **O**perational excellence, **S**ecurity, **R**eliability, **P**erformance efficiency, **C**ost optimisation, **S**ustainability.

## The AWS Well-Architected Tool

A **free** service in the console. You answer questions about a workload, and it compares your answers with the six pillars and suggests improvements.

## Exam tips

- Questions describe a goal and ask which pillar it belongs to:
  - "Recover from a failure automatically": **Reliability**
  - "Use the right EC2 size for the job": **Performance Efficiency** (or **Cost Optimisation** if it's about saving money)
  - "Reduce the carbon footprint": **Sustainability**
  - "Enable traceability" and "apply least privilege": **Security**
  - "Perform operations as code" and "make frequent, small, reversible changes": **Operational Excellence**
