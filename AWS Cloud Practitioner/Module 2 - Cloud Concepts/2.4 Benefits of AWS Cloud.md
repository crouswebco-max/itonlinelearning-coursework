# 2.4 Benefits of the AWS Cloud

## AWS's six advantages of cloud computing (learn all six)

| Advantage | Meaning |
|---|---|
| **1. Trade fixed expense for variable expense** | No big up-front hardware purchase. Pay only for what you use, when you use it |
| **2. Benefit from massive economies of scale** | AWS buys at enormous scale, so it can charge less than you'd pay running it yourself, and prices tend to drop over time |
| **3. Stop guessing capacity** | Scale up or down to match real demand, instead of buying for a guess |
| **4. Increase speed and agility** | New resources take minutes, not weeks, so teams can try ideas quickly |
| **5. Stop spending money running and maintaining data centres** | Spend time on your product, not on racking servers and fixing air-conditioning |
| **6. Go global in minutes** | Deploy in Regions around the world with a few clicks, for lower latency for users everywhere |

## Other benefits the exam uses

| Term | Meaning | Example |
|---|---|---|
| **Scalability** | Can handle growth by adding resources | Add more servers as users grow |
| **Elasticity** | Automatically adds *and removes* resources to match demand | More servers on Black Friday, fewer at night (Auto Scaling) |
| **High availability** | Keeps running with little or no downtime | Servers in two or more **Availability Zones** |
| **Fault tolerance** | Keeps working even when parts fail | If one server dies, others take over |
| **Reliability** | Works correctly and recovers from failure | Automatic backups and recovery |
| **Agility** | Fast to experiment and change | Test a new feature in minutes |

## The global infrastructure, in brief

- **Region:** a geographic area, like London, containing several Availability Zones.
- **Availability Zone (AZ):** one or more separate data centres with their own power and networking. Using several AZs gives **high availability**.
- **Edge location:** a site used by **CloudFront** to cache content close to users, for faster websites.

**Exam trap:** "scalable" and "elastic" are close. **Elastic** is the one that shrinks back down automatically to save money.
