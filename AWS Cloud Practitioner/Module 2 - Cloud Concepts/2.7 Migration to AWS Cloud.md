# 2.7 Migration to the AWS Cloud

## The 7 Rs: migration strategies

| Strategy | Nickname | What happens | Example |
|---|---|---|---|
| **Retire** | | Switch it off: it isn't needed any more | An old reporting tool nobody uses |
| **Retain** | | Keep it where it is, for now | An app with a licence that can't move yet |
| **Rehost** | "Lift and shift" | Move as it is, with no changes | Copy a server onto an EC2 instance |
| **Relocate** | "Hypervisor-level lift and shift" | Move whole virtual machines (such as VMware) without changing them | VMware Cloud on AWS |
| **Repurchase** | "Drop and shop" | Replace it with a different product, often SaaS | Move from an in-house CRM to Salesforce |
| **Replatform** | "Lift, tinker and shift" | Small changes to use a managed service, without changing the core | Move a database to **Amazon RDS** |
| **Refactor** | "Re-architect" | Rebuild it to be cloud-native | Break it into microservices on Lambda |

**From least to most effort:** Retire and Retain, then Rehost and Relocate, then Repurchase, then Replatform, then Refactor.

## Migration tools and services

| Service | What it does |
|---|---|
| **AWS Migration Hub** | One place to plan and track migrations |
| **AWS Application Migration Service (MGN)** | Rehosts servers into AWS (the main lift-and-shift tool) |
| **AWS Database Migration Service (DMS)** | Moves databases to AWS, keeping the source running during the move |
| **AWS Schema Conversion Tool (SCT)** | Converts a database's structure to a different engine, for example Oracle to Amazon Aurora |
| **AWS DataSync** | Copies large amounts of files online to AWS storage |
| **AWS Snowball Edge** | A physical device AWS posts to you, for moving huge data **offline** when the internet would be too slow |

*AWS has retired Snowmobile, and Snowcone is being phased out, so Snowball Edge is the main Snow Family device. Check the current exam guide if Snow Family devices come up.*

## Exam tips

- "Move quickly with no changes": **Rehost** (Application Migration Service).
- "Move to a managed database with minimal changes": **Replatform**.
- "Redesign to be cloud-native": **Refactor**.
- "Terabytes or petabytes of data, with a slow internet connection": **Snowball Edge**.
