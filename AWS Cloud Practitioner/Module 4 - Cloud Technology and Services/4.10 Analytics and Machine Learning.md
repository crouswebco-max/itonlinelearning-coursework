## Lab 4.10.3: Athena query on a small CSV in S3

💰 **Pennies:** Athena charges $5 per terabyte scanned, and this file is a few bytes.

**Lesson resources:**
- [`lab-files/TestData.csv`](lab-files/TestData.csv): the data (7 students and their scores)
- [`lab-files/athena-queries.sql`](lab-files/athena-queries.sql): the course's queries

The CSV uses **semicolons** (`;`) between values, not commas:

```
id;name;score
1;Bob;80
2;Sarah;72
...
```

### Part 1: Put the data in S3

1. **S3** → **Create bucket** → a unique name, like `juan-athena-data-2026` → **Create bucket**.
2. Upload **`TestData.csv`** into the bucket (at the top level, not in a folder).
   - ⚠️ The table reads **every file in the bucket** (the `LOCATION` is the whole bucket), so **keep only `TestData.csv` in it**.
3. Create a **second bucket** for Athena's results, like `juan-athena-results-2026`. Keeping results separate stops them getting mixed in with the data.

### Part 2: Set up Athena

4. Open **Athena** → **Launch query editor**.
5. If asked, go to **Settings** → **Manage** → **Location of query result:** `s3://juan-athena-results-2026/` → **Save**.

### Part 3: Run the course's queries (one at a time)

The query editor runs **one statement at a time**: paste one, click **Run**, then clear it and paste the next.

6. **First query:** create a database called `demo`:

```sql
create database demo;
```

7. **Second query:** create the table, **changing `[YOUR_BUCKET_NAME]`** to your data bucket's name (keep the `/` at the end):

```sql
CREATE EXTERNAL TABLE demo.students (
  id INT,
  name STRING,
  score INT
)
ROW FORMAT SERDE 'org.apache.hadoop.hive.serde2.OpenCSVSerde'
WITH SERDEPROPERTIES (
  'separatorChar'=';',
  'quoteChar'='"'
)
LOCATION 's3://[YOUR_BUCKET_NAME]/'
TBLPROPERTIES ('skip.header.line.count'='1');
```

8. **Third query:** see the data:

```sql
SELECT * FROM demo.students;
```

You should get **7 rows**: Bob 80, Sarah 72, Claire 55, Susan 67, John 99, Chris 98 and Pete 23.

### What each part of the table means

| Part | Meaning |
|---|---|
| `CREATE EXTERNAL TABLE` | The data **stays in S3**. The table only describes how to read it |
| `id INT, name STRING, score INT` | The columns and their types, matching the CSV's heading row |
| `OpenCSVSerde` | The **SerDe** (serialiser/deserialiser): the code that knows how to read CSV files |
| `'separatorChar'=';'` | Values are split on **semicolons**, because that's what this file uses |
| `'quoteChar'='"'` | Values wrapped in quote marks are treated as one value |
| `LOCATION 's3://…/'` | Where the data is |
| `'skip.header.line.count'='1'` | Skip the first line (`id;name;score`), because it's a heading, not data |

### Try some more queries

```sql
-- Top three scores
SELECT name, score FROM demo.students ORDER BY score DESC LIMIT 3;

-- Students who passed (50 or more)
SELECT name, score FROM demo.students WHERE score >= 50;

-- The average, highest and lowest score
SELECT ROUND(AVG(score), 1) AS average, MAX(score) AS highest, MIN(score) AS lowest FROM demo.students;
```

Under each result, notice the **Data scanned** amount. That's what Athena charges for.

### If something goes wrong

| Problem | Fix |
|---|---|
| The query returns **0 rows** | Check `LOCATION` matches your bucket name exactly, and ends with `/` |
| Every value is in **one column** | The `separatorChar` must be `';'`, to match the file |
| The heading row appears as data | Check the `skip.header.line.count` line is there |
| "No output location provided" | Set the query result location (step 5) |

### 🧹 Clean up

1. In Athena, run `DROP TABLE demo.students;`, then `DROP DATABASE demo;`.
2. Empty and delete **both** S3 buckets.

## 4.10.4 Review: exam tips

- "SQL on data **in S3**" means **Athena**. "Data **warehouse**" means **Redshift**. "**Real-time** streams" means **Kinesis**. "**Dashboards**" means **QuickSight**. "**ETL**" means **Glue**.
- "Build and train **your own** ML models" means **SageMaker AI**. "**Generative AI** models through an API" means **Bedrock**.
- Match the input to the service: **images** → Rekognition, **text meaning** → Comprehend, **speech to text** → Transcribe, **text to speech** → Polly, **chatbot** → Lex, **scanned forms** → Textract.
