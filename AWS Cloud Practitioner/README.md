# AWS Cloud Practitioner

My study notes and lab guides for the **AWS Certified Cloud Practitioner (CLF-C02)** course.

| Module | Exam domain | What it covers |
|---|---|---|
| [Module 1: Introduction](Module%201%20-%20Introduction/) | – | The exam, the domains and weightings, setting up an AWS account safely, and exam tips |
| [Module 2: Cloud Concepts](Module%202%20-%20Cloud%20Concepts/) | Domain 1 (24%) | What the cloud is, its benefits, Well-Architected, CAF, migration and cloud economics |
| [Module 3: Security and Compliance](Module%203%20-%20Security%20and%20Compliance/) | Domain 2 (30%) | Shared responsibility, IAM, security services and monitoring, with 9 labs |
| [Module 4: Cloud Technology and Services](Module%204%20-%20Cloud%20Technology%20and%20Services/) | Domain 3 (34%) | Deploying, compute, databases, networking, storage, analytics, ML and more, with 20 labs |
| [Module 5: Billing, Pricing and Support](Module%205%20-%20Billing%2C%20Pricing%20and%20Support/) | Domain 4 (12%) | Pricing models, cost tools, support plans and Trusted Advisor |
| [Module 6: Exam Preparation and Final Review](Module%206%20-%20Exam%20Preparation%20and%20Final%20Review/) | All | A cheat sheet, strategy, a 30-question mock exam and a readiness checklist |

The course quizzes are taken on the course website.

⚠️ **Labs and costs:** the labs use a real AWS account. Each lab lists what it costs and how to clean up. Set up the **zero spend budget** from Module 1 before starting any lab.
