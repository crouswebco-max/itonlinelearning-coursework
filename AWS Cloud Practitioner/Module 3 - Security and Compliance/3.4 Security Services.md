# 3.4 Security Services and Resources

## Network protection

### 3.4.2 Security groups and network ACLs

| | **Security group** | **Network ACL (NACL)** |
|---|---|---|
| **Protects** | An **instance** (such as an EC2 server) | A **subnet** (a section of the network) |
| **Rules** | **Allow rules only** | **Allow and deny** rules |
| **State** | **Stateful**: if traffic is allowed in, the reply is allowed out automatically | **Stateless**: replies must be allowed separately |
| **Default** | Blocks all incoming traffic, allows all outgoing | The default NACL allows everything |

**Exam cue:** "block a specific IP address" means a **NACL** (security groups can't deny). "Allow HTTPS into a web server" means a **security group**.

## The main security services

| Service | What it does | Exam cue |
|---|---|---|
| **AWS WAF** (web application firewall) | Filters web requests (layer 7), blocking attacks like **SQL injection** and **cross-site scripting**, and limiting request rates. Works with CloudFront, Application Load Balancers and API Gateway | "Protect a website from SQL injection" |
| **AWS Shield Standard** | Automatic, free protection from common **DDoS** attacks for all customers | "DDoS protection at no extra cost" |
| **AWS Shield Advanced** | Paid, extra DDoS protection, a 24/7 response team, and cost protection during attacks | "Advanced DDoS protection and response team" |
| **Amazon GuardDuty** | **Threat detection**: uses machine learning on logs to spot suspicious activity | "Detect compromised accounts or unusual behaviour" |
| **Amazon Inspector** | Scans EC2, container images and Lambda for **software vulnerabilities** | "Find vulnerabilities" or "missing patches" |
| **Amazon Macie** | Finds **sensitive data** (like personal information) in **S3** | "Find personal data in S3" |
| **Amazon Detective** | Investigates the root cause of security findings | "Investigate" |
| **AWS Security Hub** | One dashboard that **collects findings** from the other services and checks accounts against **security standards** | "A single view of security alerts" |
| **AWS Secrets Manager** | Stores **secrets** (like database passwords) and can **rotate** them automatically | "Store and rotate database credentials" |
| **Systems Manager Parameter Store** | Stores settings and secrets. Simpler, cheaper, with no automatic rotation | "Store configuration values" |
| **AWS KMS** | Creates and manages **encryption keys** | "Manage encryption keys" |
| **AWS Firewall Manager** | Manages WAF, Shield and security group rules across **many accounts** | "Central firewall rules across an organisation" |
| **AWS Trusted Advisor** | Checks your account against best practices, including security (like MFA on root and open ports) | "Recommendations" (see Module 5) |

## Where to find security help

- **AWS Security Center** and the **AWS Security Blog**: news and best practice
- **AWS Knowledge Center**: answers to common questions
- **AWS Trust & Safety team**: report **abuse** coming from AWS resources (like spam or attacks)
- **AWS Marketplace**: third-party security products

## Exam tips (3.4.3)

- **GuardDuty** detects threats. **Inspector** finds vulnerabilities. **Macie** finds sensitive data in S3.
- **Shield** is for DDoS. **WAF** is for web attacks (SQL injection and XSS).
- **Secrets Manager** can rotate secrets automatically. Parameter Store can't.
- **Security Hub** collects everything into one view.
