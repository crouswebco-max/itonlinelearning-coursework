# 3.2 Cloud Security, Governance and Compliance

## Key words

| Word | Meaning |
|---|---|
| **Security** | Protecting data and systems from threats |
| **Governance** | The rules and controls for how the cloud is used (who can do what, and what's allowed) |
| **Compliance** | Proving you follow laws and standards (like GDPR, or PCI DSS for card payments) |

## Compliance services

| Service | What it does | Exam cue |
|---|---|---|
| **AWS Artifact** | Download AWS's **compliance reports** (such as SOC and ISO certificates) and accept **agreements** (such as the HIPAA business associate addendum) | "Where do I get AWS's compliance **reports** or **documents**?" |
| **AWS Config** | Records how resources are configured over time, and checks them against rules | "Is this S3 bucket still private?" "What did this resource look like last week?" |
| **AWS Audit Manager** | Collects evidence automatically to prepare for audits | "Prepare for an audit" |
| **AWS Organizations** | Manage many AWS accounts together, with **consolidated billing** | "Many accounts, one bill" |
| **Service control policies (SCPs)** | Set the maximum permissions for accounts in an organisation | "Stop every account from using a certain Region or service" |
| **AWS Control Tower** | Sets up a secure multi-account environment (a "landing zone") with guardrails | "Set up many accounts following best practice" |

**Compliance programmes AWS supports** include ISO 27001, SOC 1/2/3, PCI DSS, HIPAA and GDPR. AWS being compliant **doesn't make your app compliant**: under the shared responsibility model, you still have to use the services correctly.

## Encryption

| Term | Meaning | AWS tools |
|---|---|---|
| **Encryption at rest** | Data encrypted while it's stored | **AWS KMS** (Key Management Service), **AWS CloudHSM** (your own dedicated hardware key store) |
| **Encryption in transit** | Data encrypted while it moves over a network | **TLS/HTTPS**, with certificates from **AWS Certificate Manager (ACM)**, which are free for AWS services |

## 3.2.3 Logging and monitoring, in brief (more in 3.5)

| Service | Answers the question |
|---|---|
| **AWS CloudTrail** | **Who** did **what**, and **when**? (A record of API calls) |
| **Amazon CloudWatch** | **How is it performing?** (Metrics, logs and alarms) |
| **AWS Config** | **How is it configured**, and has that changed? |
| **VPC Flow Logs** | What network traffic went in and out of the network? |

## Exam tips (3.2.2 and 3.2.4)

- "Compliance **reports**" means **AWS Artifact**.
- "Track **configuration changes**" and "**compliance rules** for resources" mean **AWS Config**.
- "Record **API calls** and user activity for auditing" means **CloudTrail**.
- "Manage **encryption keys**" means **AWS KMS**.
