# 5.3 Billing and Pricing Tools

| Tool | What it does | Exam cue |
|---|---|---|
| **AWS Pricing Calculator** | **Estimates** the cost of an architecture **before** you build it | "Estimate costs for a new project" |
| **Billing and Cost Management console** | Your bills, payments and a summary of spending | "View this month's bill" |
| **AWS Cost Explorer** | **Charts of past spending**, filtered by service, account or tag, with **forecasts** of future spend | "Analyse **past** costs and see trends" |
| **AWS Budgets** | Set a cost or usage **limit** and get **alerts** before you go over | "Alert me **before** I overspend" |
| **AWS Cost and Usage Reports** (now part of **Data Exports**) | The **most detailed** billing data, hour by hour, delivered to S3 | "The most detailed billing report" |
| **Cost allocation tags** | Labels on resources (like `Project=website`) so costs can be split by team or project | "Track costs by department" |
| **AWS Cost Anomaly Detection** | Uses machine learning to spot **unusual spending** and alert you | "Detect unexpected spikes in cost" |
| **AWS Compute Optimizer** | Recommends the **right size** for EC2, Lambda and EBS | "Rightsizing recommendations" |
| **AWS Organizations: consolidated billing** | **One bill for many accounts**, with usage **combined for volume discounts** and shared Reserved Instances and Savings Plans | "Many accounts, one bill, bigger discounts" |
| **Service Quotas** | Shows your account's **limits** for each service, and lets you **request an increase** | "We've hit the limit on EC2 instances" |
| **AWS Billing Conductor** | Custom billing views, for resellers and internal charge-backs | "Custom pricing for business units" |

## Default service limits (from the course Cram Sheet)

Every account starts with **soft limits**. They're there to stop mistakes and surprise bills, and you can ask for more in **Service Quotas**.

| Limit | Default |
|---|---|
| VPCs per Region | 5 |
| Route table entries per VPC | 50 |
| EC2 instances per Region | 20 (varies by instance type) |
| IAM groups per account | 300 |
| S3 buckets per account | 100 |

## Which tool when?

| Question | Tool |
|---|---|
| "What **will** it cost?" (before building) | **Pricing Calculator** |
| "What **did** it cost?" (the past) | **Cost Explorer** |
| "**Warn me** if it's going to cost too much" | **Budgets** |
| "**Every line** of detail" | **Cost and Usage Report** |
| "**Which team** spent it?" | **Cost allocation tags** |

## Try it

1. **Billing and Cost Management** → **Cost Explorer** → open it (it can take 24 hours the first time) → group by **Service**.
2. **Budgets:** your **zero spend budget** from Module 1 should be there.
3. **Cost allocation tags:** **Billing** → **Cost allocation tags**, to see the tags you can switch on.
