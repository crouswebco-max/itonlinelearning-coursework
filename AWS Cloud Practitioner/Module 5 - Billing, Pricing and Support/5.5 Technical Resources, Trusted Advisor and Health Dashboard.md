# 5.5 AWS Technical Resources, Trusted Advisor and the Health Dashboard

## Where to get help and information

| Resource | What it is |
|---|---|
| **AWS Documentation** | Official guides for every service |
| **AWS re:Post** | Community **Q&A** (the replacement for the old forums), with answers from AWS experts |
| **AWS Knowledge Center** | Answers to the most common questions |
| **AWS Whitepapers** | In-depth papers on architecture, security and best practice |
| **AWS Prescriptive Guidance** | Step-by-step guides and patterns for real projects |
| **AWS Skill Builder** | AWS's own training and practice exams |
| **AWS Partner Network (APN)** | Companies AWS certifies to help customers: consulting partners and software partners |
| **AWS Marketplace** | Buy **third-party software** that runs on AWS |
| **AWS Professional Services** | AWS's own experts, hired to help with big projects |
| **AWS Solutions Architects** | Help design architectures (through sales and support) |
| **AWS Trust & Safety** | Report **abuse** coming from AWS resources |

## AWS Trusted Advisor

Checks your account against **best practices** and makes recommendations, in **six categories**:

| Category | Example check |
|---|---|
| **Cost optimisation** | Idle EC2 instances and unused volumes |
| **Performance** | Over-used instances |
| **Security** | **MFA on the root user**, security groups open to the world, public S3 buckets |
| **Fault tolerance** | Resources not spread across AZs, missing backups |
| **Service limits (quotas)** | Getting close to a limit |
| **Operational excellence** | Best practice for running your workloads |

- **Basic and Developer** plans get the **core checks** only (the main security checks and service limits).
- **Business and higher** get **all checks**.

## 5.5.2 The AWS Health Dashboard

| View | Shows |
|---|---|
| **Service health** (public) | The **status of every AWS service in every Region**, for everyone |
| **Your account health** | Events that **affect your own resources**: outages, scheduled maintenance, and actions you need to take |

**Try it:**
1. In the Console, click the **bell icon** (top right) → **Open AWS Health Dashboard**.
2. **Your account health:** open issues, scheduled changes, and other notifications.
3. **Service health:** the status of AWS services by Region, and the event history.
4. **Health API:** lets programs read these events. It needs the **Business** support plan or higher.

## Exam tips

- "**Best practice recommendations** on cost, security and fault tolerance" means **Trusted Advisor**.
- "Is an AWS service having **problems that affect me**?" means **AWS Health Dashboard** (your account health).
- "Community **Q&A**" means **AWS re:Post**.
- "Buy **third-party software**" means **AWS Marketplace**.
- "Find a certified **consulting company**" means the **AWS Partner Network**.
