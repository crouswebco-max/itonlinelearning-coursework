# 1.1–1.2 Introduction and Welcome

## What the AWS Certified Cloud Practitioner is

The **AWS Certified Cloud Practitioner** (exam code **CLF-C02**) is AWS's entry-level certification. It proves you understand:

- what the cloud is, and why businesses use it
- the main AWS services and what each one is for
- how security works in AWS, and who is responsible for what
- how AWS charges for services, and the support plans available

It's a **foundational** exam, not a hands-on technical one. You don't need to write code or build servers to pass, but seeing the services in the AWS Console makes them much easier to remember.

## Who it's for

- People new to cloud and IT, like me coming from web development
- Anyone in a non-technical role who works with AWS (sales, finance, management)
- A first step before the Associate-level exams, such as Solutions Architect Associate

## Why it's useful for a web developer

- The websites and apps I build need to be **hosted** somewhere, and AWS is the biggest cloud provider.
- It explains services I'll meet when deploying projects: **S3** (storage and static websites), **CloudFront** (a content delivery network), **EC2** (servers) and **Lambda** (running code without servers).
- It's a recognised certification to add to my CV.
