# Website CSS

Practice pages for the CSS course. Every module builds on the same made-up website, **Brushstroke Paints**, so you can see the page grow as each topic is added.

| Folder | Topics |
|---|---|
| `Module 1` | Adding CSS (inline, internal, external), comments, selectors, colours |
| `Module 2` | Backgrounds, borders, margins, padding, height, width and max-width |
| `Module 3` | Text, fonts, icons, links, lists |
| `Module 4` | Position, z-index, display, max-width, overflow |
| `Module 5` | Float and clear, combinators, pseudo-classes |

Each module folder is complete on its own:

- `index.html` is the page. Open it in Chrome.
- `style.css` is the CSS. The earlier modules' CSS is at the top, and the new module's CSS is in a labelled block at the bottom.
- `README.md` says where each topic is used and has a few experiments to try.

Modules 3 to 5 load Google Fonts and Font Awesome icons, so they need an internet connection to look right.
